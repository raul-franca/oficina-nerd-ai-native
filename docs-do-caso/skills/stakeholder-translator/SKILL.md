# Stakeholder Translator

A mesma decisão muda de forma conforme quem lê. O conteúdo é um só; o **enquadramento** é o que a torna acionável para cada pessoa.

## Princípio
Isso é **framing, não maquiagem**. Os fatos e os números **não mudam** entre as versões — só a ordem, a ênfase e o que é dito primeiro. Se você precisa mudar o número para convencer alguém, você não está traduzindo: está mentindo.

## Processo
1. Identifique a **decisão ou o pedido central** antes de adaptar. Se não houver pedido claro, pare e pergunte qual é.
2. Para cada audiência, gere um bloco separado e rotulado, usando `references/audiencias.md`.
3. Nunca entregue o mesmo texto com cabeçalho trocado. **Reescreva de fato.**

## Regras
- **Liderança:** comece pela conclusão (Pyramid Principle). 1 tela. Termine com a pergunta de decisão.
- **Engenharia:** o problema técnico, a complexidade, os trade-offs e o que está **fora de escopo**.
- Um único conjunto de fatos. Só o enquadramento muda.
- Cada versão deve poder ser **enviada sem edição**.
- Se a mensagem for um "não" a alguém, ofereça sempre uma **alternativa e uma condição de reabertura**.
