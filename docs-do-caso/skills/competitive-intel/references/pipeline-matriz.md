# Pipeline

1. **Escopo** — quais concorrentes, qual dimensão (proposta de valor, features, preço, fluxo, UX).
2. **Coleta** — páginas públicas: site, planos, release notes, reviews. Com o agente de navegador, extraia direto da página.
3. **Normalização** — tudo no mesmo formato comparável.
4. **Matriz** — features × concorrentes, **com você na grade**.
5. **Filtro de três vias** (abaixo).
6. **Ameaça** — Alta / Média / Baixa, com justificativa.

## O filtro de três vias (obrigatório para cada achado)
| Classificação | O que é | O que fazer |
|---|---|---|
| **Boa prática** | Padrão consolidado que o usuário já espera (ex.: login por biometria) | **Adote.** Não é diferencial — é custo de entrada. |
| **Modismo** | Feature da moda, sem evidência de valor para o SEU usuário | **Ignore.** Registre e siga. |
| **Oportunidade real** | Lacuna que o concorrente não cobre e que bate com a sua dor de usuário | **Teste.** Vira hipótese, não roadmap. |

> A pergunta que separa modismo de boa prática: **"o meu usuário reclama da ausência disso?"** Se ninguém reclama, é modismo — por mais que o concorrente anuncie.

## Régua de ameaça
- **Alta:** ataca o seu diferencial ou o seu segmento-núcleo. Exige resposta agora.
- **Média:** relevante, mas em frente secundária. Monitorar com gatilho definido.
- **Baixa:** ruído ou nicho distinto. Registrar e seguir.

## Disciplina
Marque **fato** (estava na página) × **inferência** (sua dedução). Date a coleta. Sintetize, nunca copie literal.
