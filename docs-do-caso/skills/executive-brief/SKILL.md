# Executive Brief

Material para quem decide em 60 segundos. Estrutura **decision-first** (Barbara Minto): a resposta vem primeiro; o raciocínio sustenta, não antecede.

## Processo
Siga `references/estrutura-pyramid.md`: decisão/pedido → por que agora → 3 pilares com evidência → números que importam → trade-offs e riscos → próximos passos → **a pergunta de decisão**.

## Regras
- **Uma tela.** Passou disso, corte.
- Comece pela conclusão. **Nunca** abra com contexto histórico longo.
- Sem jargão técnico não-essencial. O leitor é sênior, mas não é do time.
- Números sem fonte viram **"(a validar)"**. Não infle para impressionar — honestidade sustenta credibilidade na sala.
- **Termine com a pergunta de decisão explícita.** Um brief que não pede nada não é um brief; é uma atualização.
- Declare os trade-offs **antes que perguntem**. Quem antecipa o próprio custo controla a narrativa.
