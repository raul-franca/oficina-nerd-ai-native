# A matriz de decisão — 7 colunas

| Coluna | O que entra | Erro comum |
|---|---|---|
| **Iniciativa** | Nome + o que é, em 1 linha | Nome vago ("melhorar UX") |
| **Alinhamento estratégico** | Alto / Médio / Baixo / **Negativo** + por quê, em 1 frase | Todo mundo vira "alto" |
| **Impacto esperado** | No objetivo do período. Com "(a validar)" se não há baseline | Inventar número para justificar |
| **Esforço** | Estimativa da squad, em tempo | Confundir esforço com complexidade |
| **Risco** | Técnico + político + de execução | Só olhar risco técnico |
| **Dependências** | Filas, outras áreas, outras iniciativas | Esquecer a fila da outra área |
| **Recomendação** | FAZER JÁ / FAZER / PRÓXIMO CICLO / NÃO AGORA / NÃO | Recomendar tudo |

## Alinhamento NEGATIVO existe
Iniciativa que **piora** o objetivo (ex.: empurrar tráfego para um funil que não converte aumenta o custo por atendimento). Marque como negativa e explique. É o achado mais valioso da matriz.

## Habilitadores
Alguns itens não movem a métrica sozinhos (ex.: instrumentação), mas **destravam todos os outros**. Impacto = "habilitador". Vão primeiro na sequência, mesmo com impacto direto baixo.
